On Debian Jessie, the PHP 5.6 packages from `deb.sury.org` are named `php5.6-bcmath`, but the official Debian Jessie repositories use `php5-bcmath` (for PHP 5.6 as the default PHP version).

Since you're using the official `docker-library/php` image based on `debian:jessie`, the PHP packages come from the default Debian repositories, not from `deb.sury.org`. Therefore, the correct package name is:

```bash
apt-get update
apt-get install -y php5-bcmath
```

If that doesn't work, check whether the package lists are up to date and whether the `php5-bcmath` package exists in your configured repositories:

```bash
apt-get update
apt-cache search php5 | grep bcmath
```

If you see `php5-bcmath` in the search results, install it with:

```bash
apt-get install -y php5-bcmath
```

After installation, verify that the bcmath extension is loaded:

```bash
php -m | grep bcmath
```

If you're using Apache with `mod_php`, restart Apache to load the new extension:

```bash
apache2ctl restart
```

If you're using PHP-FPM, restart the FPM service:

```bash
service php5-fpm restart
```

**Note:** The `docker-library/php` image for PHP 5.6 on Jessie is based on the official Debian packages, so `php5-bcmath` is the correct package name. The `php5.6-bcmath` naming convention is specific to the `deb.sury.org` repository, which is not enabled by default in this image.
