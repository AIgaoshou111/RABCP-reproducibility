The error you're seeing (`Chrome failed to start: crashed`) is a common issue when running Chrome in Docker containers, especially with ChromeDriver 2.31 and headless Chrome in 2017.

## Root Cause

Chrome requires several system libraries and a proper environment to run, even in headless mode. In a minimal Ubuntu Xenial container, these dependencies are missing, causing Chrome to crash immediately upon startup.

## Solution

Add these dependencies to your Dockerfile:

```dockerfile
FROM ubuntu:xenial

# Install Chrome dependencies
RUN apt-get update && apt-get install -y \
    libnss3 \
    libx11-xcb1 \
    libxcomposite1 \
    libxcursor1 \
    libxdamage1 \
    libxi6 \
    libxtst6 \
    libxrandr2 \
    libasound2 \
    libatk1.0-0 \
    libatk-bridge2.0-0 \
    libcups2 \
    libdrm2 \
    libgbm1 \
    libgtk-3-0 \
    libnspr4 \
    libnss3 \
    libxss1 \
    wget \
    --no-install-recommends

# Install Chrome
RUN wget -q -O - https://dl-ssl.google.com/linux/linux_signing_key.pub | apt-key add - \
    && echo "deb http://dl.google.com/linux/chrome/deb/ stable main" >> /etc/apt/sources.list.d/google-chrome.list \
    && apt-get update \
    && apt-get install -y google-chrome-stable

# Install ChromeDriver
RUN wget -q https://chromedriver.storage.googleapis.com/2.31/chromedriver_linux64.zip \
    && unzip chromedriver_linux64.zip \
    && mv chromedriver /usr/local/bin/ \
    && chmod +x /usr/local/bin/chromedriver \
    && rm chromedriver_linux64.zip
```

## Additional Required Flags for Headless Chrome

When running Chrome in Docker, you need to add these flags to prevent crashes:

```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

chrome_options = Options()
chrome_options.add_argument("--headless")
chrome_options.add_argument("--no-sandbox")  # Required in Docker
chrome_options.add_argument("--disable-dev-shm-usage")  # Prevent crashes in containers
chrome_options.add_argument("--disable-gpu")  # Recommended for headless

browser = webdriver.Chrome('/usr/local/bin/chromedriver', chrome_options=chrome_options)
```

## Key Points

1. **`--no-sandbox` is critical**: Chrome's sandbox requires specific kernel features that aren't available in Docker containers by default.

2. **`--disable-dev-shm-usage`**: Docker containers have limited `/dev/shm` (typically 64MB), which can cause Chrome to crash. This flag makes Chrome use `/tmp` instead.

3. **Complete dependency installation**: The `libnss3` fix you found is necessary but not sufficient. Chrome needs many more libraries to run properly.

4. **Use `--no-install-recommends`**: This keeps your image smaller while still installing required dependencies.

## Verification

After building the Docker image, test with:

```bash
docker run -it your-image python -c "
from selenium import webdriver
from selenium.webdriver.chrome.options import Options
options = Options()
options.add_argument('--headless')
options.add_argument('--no-sandbox')
options.add_argument('--disable-dev-shm-usage')
driver = webdriver.Chrome('/usr/local/bin/chromedriver', chrome_options=options)
driver.get('http://example.com')
print(driver.title)
driver.quit()
"
```

This should print "Example Domain" without errors.
