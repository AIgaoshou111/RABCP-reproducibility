The problem is that you're sending the request body as URL-encoded form data, but the Docker Remote API expects JSON.

Your curl command sends:
```
{"Image": "registry:2"}
```

But your Java code sends form-encoded data like:
```
Image=registry%3A2
```

The error `invalid character 'I' looking for beginning of value` occurs because Docker tries to parse the body as JSON but finds `Image=...` instead.

**Fix:** Send a JSON string as the request body instead of form-encoded parameters.

Here's the corrected Java code:

```java
import org.apache.http.client.HttpClient;
import org.apache.http.client.methods.HttpPost;
import org.apache.http.entity.StringEntity;
import org.apache.http.impl.client.DefaultHttpClient;

String containerName = "test_remote_reg";
String imageName = "registry:2";
String url = "http://192.168.59.103:2375/containers/create?name=" + containerName;

HttpPost post = new HttpPost(url);
post.setHeader("Content-Type", "application/json");

// Build JSON body manually or use a JSON library
String jsonBody = "{\"Image\": \"" + imageName + "\"}";
StringEntity entity = new StringEntity(jsonBody);
post.setEntity(entity);

HttpClient client = new DefaultHttpClient();
client.execute(post);
```

**Better approach using a JSON library (e.g., Jackson or Gson):**

```java
// Using Gson
Gson gson = new Gson();
Map<String, String> body = new HashMap<>();
body.put("Image", imageName);
String jsonBody = gson.toJson(body);

StringEntity entity = new StringEntity(jsonBody);
post.setEntity(entity);
```

**Key changes:**
1. Use `StringEntity` instead of `UrlEncodedFormEntity`
2. Set the body as a JSON string: `{"Image": "registry:2"}`
3. Keep the `Content-Type: application/json` header

This will match what your curl command does and should work correctly with the Docker Remote API.
